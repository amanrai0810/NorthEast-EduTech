# NorthEast EduTech

Premium, responsive React + Vite landing website for NorthEast EduTech.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Customize before launch

- Replace placeholder phone/email/WhatsApp number.
- Replace Arunachal Pradesh map placeholder with a real Google Maps embed.
- Replace demo portfolio concepts with real screenshots and verified projects.
- Replace sample testimonials with verified client testimonials.
- Connect the consultation form to your preferred backend/email service.
- Add real social profile URLs.
